03 / FERRAMENTAS

Comandos que todo desenvolvedor conhece.

Conheça alguns comandos essenciais do Git. Você pode copiar cada um deles.

01 / INICIALIZAÇÃO ⌘

Iniciar repositório

Inicializa um novo repositório Git na pasta atual.

git init
02 / PREPARAÇÃO ▤

Adicionar arquivos

Prepara as alterações para serem registradas.

git add .
03 / REGISTRO ✓

Registrar alterações

Cria um registro das alterações preparadas.

git commit -m "Meu projeto"
04 / BRANCH ⑂

Definir branch principal

Define o nome da branch principal como main.

git branch -M main
05 / CONEXÃO ↔

Conectar ao GitHub

Conecta o repositório local ao remoto.

git remote add origin URL
06 / PUBLICAÇÃO ↗

Enviar para o GitHub

Envia os commits da branch main para o GitHub.

git push -u origin main
07 / ATUALIZAÇÃO ↓

Receber atualizações

Busca e integra alterações do repositório remoto.

git pull
08 / CONSULTA ◉

Consultar status

Mostra a situação atual dos arquivos no Git.

git status
ⓘ

Os comandos são executados no terminal, dentro da pasta do projeto, após instalar e configurar o Git. O comando de conexão exige substituir URL pelo endereço real do seu repositório.

07 / BOAS PRÁTICAS

Compartilhe com responsabilidade.

Antes de publicar um projeto, confira alguns cuidados importantes.

🔐

Proteja suas senhas

Nunca coloque senhas, tokens de acesso ou chaves privadas nos arquivos publicados.

👤

Cuide dos dados pessoais

Não publique documentos, endereços, telefones ou informações privadas.

©

Respeite os direitos autorais

Utilize materiais próprios ou recursos cuja licença permita o compartilhamento.

🌐

Escolha a visibilidade correta

Confira se o repositório deve ser público ou privado antes de compartilhar.
